# 네컷 부스 (necut-booth)

아이패드/안드로이드 웹브라우저에서 쓰는 무인 네컷 사진 부스.
흐름: 틀 선택 → 6번 촬영 → 잘 나온 4장 선택 → 합성 → QR 표시 → 관람객이 QR로
접속해서 사진 다운로드 → 촬영 기기 자동으로 첫 화면 복귀.

🔗 https://fourcuts.onrender.com

## 이용방법

시작하기 버튼 → 프레임 선택 → 사진 찍기(6회) → 사진 고르기 → 다운로드

## 필름 프레임 추가 방법

추가할 프레임 준비 (사진이 들어갈 공간은 빈 공간(투명)으로 준비)
png로 저장 후 frames 파일에 집어 넣은 후 'frames.js'파일에

```
{
    id: "[파일이름]",
    name: "[프레임 이름]",
    hasImage: true,
    image: "[프레임png가 들어가 있는 주소]",
    width: 1024,
    height: 1536,
    slots: [ // 사진이 들어갈 위치를 좌표로 알려줌
      { x: 284, y: 142, w: 457, h: 292 },
      { x: 285, y: 453, w: 456, h: 294 },
      { x: 285, y: 766, w: 456, h: 291 },
      { x: 288, y: 1080, w: 453, h: 288 },
    ],
  },
```
